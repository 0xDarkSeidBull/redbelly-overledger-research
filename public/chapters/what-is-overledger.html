02Overledger

What is Overledger?

Confirmed

Overledger is Quant's platform for building applications that span more than one blockchainS12. It has three foundations: a Gateway that authenticates clients, routes requests and is also the way in to the Fusion RollupS13; Connectors, one for each chain family such as EVM or SolanaS13, that put that family's RPC protocol behind one common interfaceS13; and the Fusion Rollup, a shared layer that anchors to several chains at once and supports deposits, withdrawals and cross-chain messages between themS13.

Analysis

In plain terms, the Gateway and Connectors are a switchboard: one login and one interface to talk to many chainsS13. The Fusion Rollup is different. It is a separate EVM-compatible layer: tokens deposited from the chains connected to it appear as balances on the rollup and can be withdrawn back to those chainsS13. The rollup connects to only a subset of the networks the Gateway reachesS13, so a chain can be reachable through the switchboard without being connected to the Fusion Rollup.

Confirmed

Multi-step workflows such as signing or deploying a contract run as Flow AppsS12. Signing can be done with the user's own keysS14, and neither the calling Flow App nor the Gateway ever sees themS14.
