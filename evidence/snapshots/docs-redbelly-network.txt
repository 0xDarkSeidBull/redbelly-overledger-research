The Redbelly Network is a layer 1 blockchain, built and optimised for real world asset tokenisation. It consists of a global network of nodes running an innovative democratic byzantine fault tolerant consensus algorithm and a scalable EVM implementation. In addition to the network infrastructure, Redbelly provides real world asset tokenisation protocols and SDKs for developers to use to build their use case.
