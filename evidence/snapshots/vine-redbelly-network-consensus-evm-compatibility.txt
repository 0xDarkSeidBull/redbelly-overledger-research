EVM compatibility and version details¶

Redbelly is compatible with the Ethereum Virtual Machine (EVM) and can execute smart contracts written for the EVM. There are, however, a few things to keep in mind and detailed below.

EVM version¶
Prague

Solidity version¶
v0.8.30

Gas prices¶

Gas prices on Redbelly are fixed in USD terms. See Network fees for more information.
