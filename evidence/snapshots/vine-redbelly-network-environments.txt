Currency symbol:	RBNT

Public RPC providers

Third-party public endpoints for Mainnet.

Ankr	https://rpc.ankr.com/redbelly_mainnet	View docs
Uniblock	https://api.uniblock.dev/uni/v1/json-rpc?chainId=151	View docs

Note

Uniblock requires an API key on the x-api-key header for this endpoint. Get a free key at uniblock.dev.
