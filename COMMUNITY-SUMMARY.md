# Community summary

Plain language summary of the report, ready to share.

Could Redbelly connect to Quant's Overledger? We looked only at public documents. Redbelly and Quant have not announced any partnership or talks, and this research does not suggest any.

Overledger is Quant's platform for reaching many blockchains through one interface. It supports any EVM chain through a self-serve route, and Redbelly is EVM compatible. So a basic connection, reading Redbelly and sending transactions that the sender has signed, looks possible, but nobody has tested it yet. Every Redbelly rule would still apply, including the access credential that every sending account needs.

Overledger's Fusion Rollup, its shared layer for moving tokens between chains, does not include Redbelly, and there is no self-serve way to add a chain. That part is not possible today.

Receptor credentials and Tokeniser's eligibility rules are enforced on Redbelly. They do not travel with a token to another chain. Keeping regulated assets on Redbelly avoids that gap.

Open questions: whether Redbelly passes Overledger's network check, which chains The Clearing House network will reach, and Redbelly's own position on bridging. The full report and every source are linked below.

## As an X thread

1/ The Clearing House picked Quant to power its tokenised deposit network, so people are asking: could Redbelly connect to Quant's Overledger? We read the public docs. No partnership or talks between Redbelly and Quant have been announced.

2/ Overledger reaches many chains through one interface. Any EVM chain can be added through a self-serve route, and Redbelly is EVM compatible. A basic connection for reading data and sending signed transactions looks possible, but it is untested.

3/ Redbelly's rules still apply on that route. Every account that sends a transaction needs a Redbelly access credential, and Tokeniser checks eligibility on every transfer.

4/ Overledger's Fusion Rollup, which moves tokens between connected chains, does not include Redbelly and has no self-serve way to add a chain. Not possible today.

5/ Receptor credentials and Tokeniser rules do not travel with a token to another chain. A copy elsewhere follows only that chain's rules. Keeping regulated assets on Redbelly avoids the gap.

6/ Still unknown: whether Redbelly passes Overledger's network check, which chains The Clearing House network will reach, and Redbelly's position on bridging. Full report with a source for every claim: https://overledger.test-hub.xyz
